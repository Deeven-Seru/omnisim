INV-01 · Connection Headroom

Datastore Pool Ceiling

Guarantees open database sockets never exceed 85% of physical instance capability. Eliminates queue starvation under sudden bursts.

Condition: pool_saturation ≤ 0.85
INV-02 · Concurrency Bound

Thread Fanout Starvation

Guarantees horizontal compute scaling does not exceed backend downstream connection limits. Prevents autoscaling-induced database crashes.

Condition: worker_threads × nodes < max_conn
INV-03 · Cascading Dampening

P99 Latency Bound

Limits service tail latency under retry storms. Halts recursive microservice amplification loops before upstream gateways time out.

Condition: timeout_p99 ≤ 120ms

Condition: active_zones ≥ 3
