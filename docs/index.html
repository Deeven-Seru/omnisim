02 // Core Architecture

Foundations of Causal Simulation

CAPABILITY // 01
Causal Graph Ontology
Compiles Terraform declarations, Kubernetes topologies, and live metrics into a directed relational dependency graph. Computes physical limits (AWS RDS max_connections formulas, buffer saturation, TCP thread pools) directly from specifications.
CAPABILITY // 02
Counterfactual MCTS Search
Searches alternative intervention trajectories using Monte Carlo Tree Search conditioned on action sequences: $S_{t+1} = f_\theta(S_t, A_t) + \epsilon$. Punishes invariant failures quadratically to discover Pareto-optimal stability paths.
CAPABILITY // 03
Autonomous Remediation Synthesis
When invariants breach, the engine generates an automated Git unified diff patch. Replaces inadequate instance tiers with verified sizing headroom directly in HCL code before any merge approval.
